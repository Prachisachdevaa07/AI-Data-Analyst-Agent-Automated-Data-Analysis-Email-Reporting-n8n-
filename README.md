# AI Data Analyst Agent – Automated Data Analysis & Email Reporting

An AI-powered Data Analyst Agent built using **n8n, OpenAI, Google Sheets, and Gmail**. It allows users to interact with spreadsheet data through a chat interface and receive automated analytical reports via email.

## 🛠️ Tools & Technologies

- **n8n** – Workflow automation
- **OpenAI Chat Model** – AI-powered query processing
- **Simple Memory** – Conversational memory
- **Google Sheets** – Data source and retrieval
- **Gmail** – Automated email reporting

## ⚙️ How It Works

1. User sends a query through the chat interface.
2. The AI Agent receives and interprets the request.
3. OpenAI Chat Model processes the query.
4. Simple Memory maintains conversational context.
5. Google Sheets retrieves the required data.
6. The AI Agent analyses the retrieved information.
7. Gmail automatically sends the analytical report.

## 🚀 Key Features

- Conversational data analysis
- AI-powered customer analysis
- Google Sheets integration
- Automated email reporting
- City-wise customer analysis
- AI agent with memory
- Workflow automation using n8n
